# Joint arithmetic query objective

Starting point: Q3 in the fifteen-cycle package certifies a(5) using seven linear multiples after exactly recovering a(2),a(3). It does not use uncertain a(7), a(49), or the nonlinear a(25),a(50) relation.

Before confirmatory calculation, the objective is to construct a finite set of actual quadratic templates indexed by (a(5),a(7)) after the two certified anchors. Retain every n<=50 supported on primes2,3,5,7 with a factor5 or7. Use pairwise linear-function bounds in the *actual reused-grid sensor norm* and complete inherited tail bounds, rather than replacing correlated decoded sensor noise with independent coordinate errors. The final decoder should return a unique query among all feasible templates; it must not require a(7) to be separately recovered or choose a budget using the unknown true template.

Acceptance requires a rigorous conditional improvement over Q3 or an informative proved limitation, a full finite coverage/realizability argument, complete-tail propagation, a strict callable checker/decoder, and adverse controls. Any optimum stated will concern the declared pairwise sufficient certificate. A sharp physical minimax threshold is not assumed attainable by this method.
