Primary box: |u|, |v|, |epsilon| <= 1/10000. One epsilon is shared globally and acts by actual time exp(epsilon)*tau. The initial preparation is an unknown bounded offset, not an observed source parameter and not fitted away. Sensor noise obeys ||W^(1/2)n||_2 <= 1/10000000.

Compare selected group budget shares (2/3,1/3,0) with uniform (1/3,1/3,1/3); uniform on the same active A/B groups (1/2,1/2,0) is a secondary control. A zero share omits the corresponding rows. No free arbitrary global sensor is acquired: the global statistic is post-processing the measured local sensors.

Decision statistic: the independently checked rational finite inverse-stability diameter certificate, using a fixed nominal weighted least-squares left inverse. Require kappa<1. Report both joint (u,v,epsilon) infinity-norm diameter and the sharper bound for physical u,v coordinates. Compare sufficient guarantees only, not actual optimality or minimax risk. A rejected bound is INCONCLUSIVE, never impossibility.

The prior pilot used parameter radius 1e-7 and preparation radius 1e-8 to verify feasibility of the new integrator. It inspected interval widths but did not evaluate comparative design outcomes. If the primary sufficient gate fails, preserve that result; restrict the box or use declared uniform subdivision without searching budget shares. This is model-conditional and has no empirical apparatus claim.
