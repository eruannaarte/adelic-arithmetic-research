# Five-path claim and evidence index

This index distinguishes complete mathematical arguments, finite numerical proofs, reconstructed historical results, and implementation controls. All claims are conditional on their stated models. None is a literature-priority or hardware-validation claim. The [master proof appendix](/Volumes/KINGSTON/Vibecoding/Math/research/five_paths_2026_09/PROOF_APPENDIX.md) provides the full proof map, accepted theorem dependencies, and exact reproduction commands.

**Status key:** **A** = analytic argument supplied, with explicitly accepted standard theorems; **C** = exact rational or outward numerical certificate, conditional on its analytic enclosure argument and arithmetic implementation; **R** = historical result/premise reconstructed, not presented as new; **V** = finite implementation control, not proof of a universal mathematical statement. A+C means both layers are required. Displayed approximations are not certificate inputs; exact endpoints in the linked JSON files decide inequalities.
