# What the developed transfer theorem adds

The theorem now gives exact criteria for information-preserving reductions and quantitative conditions for safe approximate recovery. Its [complete statement and proof](/Volumes/KINGSTON/Vibecoding/Math/research/transfer_theorem_2026_09/framework/PROOFS.md) is organized around the actual experiment, including shared nuisance, the physical noise metric, retained measurements, and every approximation error.

**Restriction and nuisance elimination have one exact geometry.** Whiten the original noise, let L be the retained row space and N the unrestricted nuisance range. The minimum noise needed to explain a retained observation is the norm of its projection onto L intersect N-perp. A lifting proof constructs an admissible nuisance and noise vector, so this is an equivalence of answer sets. Correlated noise on retained coordinates uses the inverse of the retained covariance-form block, not a principal block of the original precision matrix.

**Commutation and preservation are different properties.** The restricted full nuisance quotient can be implemented using only retained readings exactly when the retained row space is invariant under the nuisance-orthogonal projection. Reconstructing the entire quotient requires the stronger condition that every discarded direction is nuisance. A specific coarser query can survive under a weaker, exact criterion: each answer-class observation union must be saturated along discarded fibers within the promised data domain. Equal worst-case error or equal noiseless kernels does not imply pointwise equality of the conditional answer sets.

**Approximate stages compose through their errors.** A verified outer model contains every actual answer. Linear stages propagate shared primitive errors before their norms or directional supports are bounded. For compact convex response templates, optimizing those supports exactly recovers their distance and the noise threshold for disjointness. Convexifying a nonlinear union of answers can create false ambiguity, so alternatives must remain separate until feasibility has been checked.

**Restricted sensing receives a whole-source certificate.** For two label-dependent approximate maps A_j,A_k, a lower Gram bound lambda on [A_j,-A_k] separates their complete nonzero-source tubes whenever lambda exceeds the sum of the two squared relative error budgets. Each budget includes model error, sensor noise and numerical error in the same declared norm. A separate individual-map floor provides the continuous-source enclosure. Closed parameter cells with outward remainders transfer these guarantees to continuous time.

**Numerical implementation has an explicit limit.** Even a tiny nonzero nuisance-projector defect creates unbounded leakage under arbitrary nuisance amplitude. The proof therefore requires exact annihilation, an amplitude bound or a verified computation residual. A normal-residual certificate gives an explicit inverse-error allowance; a small floating residual without an error bound is not itself a certificate.

The executable interface reproduces all **687** prior scalar gates across three models and **392** new polynomial gates after the model-specific checkers establish their inputs. It additionally checks the same 392 gates with a conditional exact-model normal residual of 10^-8. For the eleven-row spatial bank, three global metric contracts pass the same pair and inverse theorem with all 231 source/label cases covered over continuous time. Including the model error and a conditional computed-data allowance of 10^-9 times the source norm still gives source error below 0.000962 for an exact final inverse.

These are demonstrated uses of common arguments, not hundreds of independent theorems. The polynomial and separated-sensing applications attach new model reconstructions to the same transfer contracts. General projection and optimal-recovery theory is classical; the contribution claimed here is the explicit integration and its certified model consequences.
